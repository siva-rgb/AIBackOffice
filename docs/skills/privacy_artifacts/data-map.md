# Security — Data Map

Every piece of data Kora collects, where it lives, how long it's kept,
and who can access it. This is the source of truth for the privacy policy.

---

## Data collected directly from the user

| Data | Where stored | Retention | Encrypted | Purpose |
|---|---|---|---|---|
| Email address | `users.email` (Supabase) | Until account deletion | At rest (Supabase) | Authentication, communication |
| Full name | `users.full_name` | Until account deletion | At rest | Display, invoice sender |
| Business name | `users.profile.business_name` | Until deletion | At rest | Invoices, contracts, branding |
| Business address | `users.business_address` | Until deletion | At rest | Invoice sender address |
| Tax ID / VAT / GSTIN | `users.tax_id` | Until deletion | At rest | Invoice compliance |
| Country, timezone, currency | `users.profile.*` | Until deletion | At rest | Localization, compliance |
| Monthly revenue goal | `users.profile.monthly_revenue_goal` | Until deletion | At rest | Briefing, goal tracking |
| Transaction CSV data | `transactions` table | 7 years (tax compliance) | At rest | Bookkeeping, P&L |
| Invoice data | `invoices` table | 7 years | At rest | Billing, follow-ups |
| Contract content | `contracts` table + GCS PDF | 7 years | At rest | Legal documents |
| Client names, emails, addresses | `clients` table + `invoices` | Until deletion | At rest | Client management |
| Quick capture notes | `quick_captures` table | Until deletion | At rest | Business context capture |
| Meeting notes | `meetings` table | Until deletion | At rest | Client relationship tracking |

## Data collected from Google (when connected)

| Data | Where stored | Retention | Encrypted | Purpose |
|---|---|---|---|---|
| Google OAuth access token | `google_connections.access_token_enc` | Until disconnect | **Fernet encrypted** | API authentication |
| Google OAuth refresh token | `google_connections.refresh_token_enc` | Until disconnect | **Fernet encrypted** | Token refresh |
| Gmail address | `google_connections.google_email` | Until disconnect | At rest | Display, email matching |
| Gmail thread snippets (client threads only) | `email_intel_cache.summary` | 24 hours | At rest | Client communication intelligence |
| Calendar event titles + attendees | In-memory only (not persisted) | Per-request | N/A | Morning briefing |
| Drive file names + content (Kora folder only) | `drive_doc_cache` (metadata only) | Until processed | At rest | Document classification |
| Meeting transcript text | `meetings.raw_transcript` | Until deletion | At rest | MOM extraction |

**Critical: Gmail and Drive data handling**

- Only threads where at least one participant matches a `clients.email` are read
- Only files in the user-designated "Kora" folder or auto-saved Meet transcripts are read
- Raw email bodies are NEVER stored — only AI-processed summaries
- Raw email bodies are NEVER logged to Sentry or agent_logs
- Calendar event descriptions are NOT read unless client-related
- Data is sent to Google Vertex AI / Gemini for processing (see AI processing section)

## Data shared with third parties

| Third party | What data | Purpose | Their compliance |
|---|---|---|---|
| Google Cloud (Vertex AI / Gemini) | Transaction descriptions, email snippets, contract terms, meeting transcripts — sent as prompt content | AI processing | Google Cloud DPA, ISO 27001, SOC 2. Vertex AI does NOT use customer data for model training |
| Supabase | All structured data | Database hosting | SOC 2 Type II, GDPR DPA available |
| Stripe | Payment card details (handled by Stripe, never touches Kora) | Payment processing | PCI DSS Level 1 |
| Resend | Recipient email addresses + email content | Email delivery | GDPR compliant, DPA available |
| Google (Gmail/Calendar/Drive APIs) | API requests to read/write user's own data | Google integration | Google API ToS, user consented via OAuth |
| Sentry | Error stack traces (financial data stripped) | Error monitoring | SOC 2, GDPR DPA |

**We do NOT share data with:**
- Advertisers (Kora has no ads)
- Data brokers
- AI training datasets (not ours, not Google's, not anyone's)
- Any other third party not listed above

## Data that Kora explicitly does NOT collect

- Credit card numbers (Stripe handles all payment card data)
- Social Security numbers or government ID numbers
- Bank login credentials (CSV upload only, not bank API)
- Personal email content (only client-related threads)
- Browsing history
- Location data (beyond the country in profile)
- Device identifiers
