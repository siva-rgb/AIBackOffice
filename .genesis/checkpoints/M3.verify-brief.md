## 4 · Document review (qualitative)

## 5 · Open caveats from maker

- The mock-mode escape hatch (`_fernet = None` when `KORA_DATA_BACKEND == "mock"`)
  was **removed** — even in mock mode, missing key now fails the process.
  This is stricter than the literal context-graph invariant ("in production
  mode"). Verifier should decide if this is a **spec violation** (overreach)
  or a **safety improvement** (catches a class of dev mistakes where someone
  switches from mock to supabase mode without setting the key).

- The verifier is running with **the same model in the same session** as the
  builder (per maker's checkpoint iter 2 note). The strict LOOPS.md protocol
  demands fresh-context separation — flag if you conclude this is insufficient.
