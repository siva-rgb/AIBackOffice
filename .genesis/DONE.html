1 · The Locked Spec (what we are building)

Cognitive job: Harden an AI-powered business back-office (Kora) from a functional MVP into an enterprise-grade, secure, observable, and performant platform. The system must provide tenant-isolated SAAS operations — AI-driven bookkeeping, contract review, calendar intelligence, Gmail integration, cashflow analysis, and Stripe billing — while implementing the security, compliance, and reliability controls expected of a production system handling PII and financial data.

Inputs: User financial data (transactions, invoices, contracts), Gmail messages via OAuth, Stripe webhooks, Notion integration, user-uploaded documents  →  Outputs: AI-generated reports (cashflow, bookkeeping, contract reviews), categorized transactions, notification alerts, PDF reports, audit logs, GDPR-compliant data exports

Autonomy level: Supervised autonomy — AI agents drive analysis/categorisation, but financial decisions, deletions, and bulk operations require human approval  |  Human-in-the-loop points: Contract review approval, bulk transaction categorisation, data export/deletion requests, plan/billing changes

Failure tolerance: Zero tolerance for cross-tenant data leakage, token encryption failure, or silent billing errors. Graceful degradation acceptable for non-critical LLM-dependent features (dashboard slow is OK; wrong tenant data is NOT)  |  Trust boundary: Multi-tenant SaaS — Google OAuth tokens, Stripe payment data, PII (tax IDs, addresses). Every query must be tenant-scoped. All outbound calls to external APIs (Gmail, Notion, Stripe, Supabase) require authenticated pipelines with timeout/circuit-breaker.

Filled during Genesis step G0 (Cognitive Design) via agentic-swe-master.
