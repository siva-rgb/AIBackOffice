**The load-bearing technical constraint (found by reading, not by failing):**
`app/store.py` picks its backend **at import time** from `settings.KORA_DATA_BACKEND`, and
`app/config.py` instantiates `Settings()` at import, reading the developer's real `.env`
(`KORA_DATA_BACKEND=supabase`, live `MODEL_API_KEY`, live `NOTION_API_KEY`). Therefore `conftest.py`
must mutate `os.environ` **at module level, before any `app.*` import** — pytest loads `conftest.py`
before test modules, and pydantic-settings ranks real env vars above the dotenv file, so this wins.
Without it the suite would hit the live Supabase project and the live LLM gateway.

**Files (freeze boundary — no `app/` changes):**
1. `backend/pytest.ini` — testpaths, quiet, pin `asyncio_default_fixture_loop_scope`
2. `backend/conftest.py` — hermetic env (mock backend, blank LLM + Notion creds) + unique-user fixture
3. `backend/tests/test_memory_recall.py` — lexical fallback, semantic ranking (injected vectors), client scoping
4. `backend/tests/test_task_ledger.py` — auto-capture idempotency ×3, brief dedupe, stats/overdue
5. `backend/tests/test_notion_connector.py` — mapping round-trip, **tenant-isolation guard**, graceful degradation
6. `backend/tests/test_profile_completeness.py` — raw-dict coercion

**Isolation strategy:** `memory_store` keeps state in module-level dicts/lists, so every test takes a
**unique uuid user_id** from a fixture rather than mutating/reset­ting private module state. Cheaper and
less brittle than reaching into `_tasks` / `_agent_memory`.

**Demo:** `cd backend && KORA_DATA_BACKEND=mock venv/Scripts/python.exe -m pytest -q` → exit 0, non-zero count.

### Decisions
- Tests target **services directly, not HTTP routes** — M0's criteria are about service behaviour, and skipping TestClient/ASGI keeps the suite at 0.74s. Route-level tests belong to M5 (plan gating), which genuinely needs `app.dependency_overrides`.
- Per-test **unique uuid `user_id`** instead of resetting `memory_store`'s module-level dicts — isolation without touching private state.
- `fake_embeddings` fixture returns `None` for unregistered text, mirroring real provider failure, so the fallback path stays reachable.
